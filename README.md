## 📖 项目简介

谋策智能体是一款融合中国传统谋略智慧与现代决策科学的开源 AI 工具。它整合了**鬼谷子**的纵横捭阖之术、**孙子兵法**的战略战术思想、**三十六计**的兵法策略、**资治通鉴**的历史案例，以及**毛泽东思想**的实事求是方法论，为用户提供系统化、可落地的决策分析。

### 核心特色

- 🧠 **五大智慧体系**：鬼谷子 + 孙子兵法 + 毛泽东思想 + 三十六计 + 资治通鉴
- 📋 **六步分析框架**：矛盾拆解 → 谋略匹配 → 方案推演 → 风险评估 → 落地拆分 → 复盘提示
- 🎯 **十大场景模板**：通用决策 / 创业决策 / 职场决策 / 投资决策 / 婚恋决策 / 教育决策
- 💬 **多轮对话记忆**：支持上下文连贯的连续对话
- 📎 **文件上传分析**：支持 PDF/Word/TXT/Markdown 文件联合分析
- 🤖 **多模型兼容**：支持 GLM-4 / Kimi / MiniMax 等国产大模型
- 🖥️ **双界面支持**：Web 可视化界面 + 命令行交互
- 💾 **结果导出**：自动生成 Markdown 格式分析报告
- 🧠 **独立动态智慧库**：基于真实案例复盘学习，持续进化决策能力（V2.1 新增）
- 📚 **独立知识库**：智库与代码分离，支持热更新和独立维护（V2.1 新增）

## 🆕 V2.2 进化版新特性

### 独立知识库架构

V2.1 将智库从代码中独立出来，实现：

- **独立维护** - 知识内容升级无需修改主代码
- **热更新** - 运行时动态重载知识库
- **版本管理** - 知识库独立版本号
- **便捷扩展** - 通过 JSON 文件即可补充新谋略

独立知识库位置：`../strategy-knowledge-base/`

### 独立动态智慧库

V2.2 增强了**质量检查** (Dynamic Knowledge Base)**，赋予智能体从真实案例中学习的能力：

- **持久化存储**：本地 `data/wisdom_library.json` 存储实战经验
- **自动检索**：处理新决策问题时，自动检索相关历史教训作为前置启示
- **持续进化**：智慧库随使用不断增加，智能体决策能力越来越"老辣"

### 实战案例复盘机制

新增 `learn_from_feedback` 接口，支持"战后复盘"：

1. 输入原始决策问题
2. 输入实际采取的行动
3. 输入真实世界的反馈结果
4. 大模型自动提炼 1-2 条核心实战智慧规则
5. 永久存入智慧库供后续调用

### 管理员复盘终端

纯命令行后台工具 `admin_feedback_cli.py`，专供管理员使用：

```bash
python admin_feedback_cli.py
```

交互式录入案例，一键驱动智能体完成深度复盘。

## 🚀 快速开始

### 环境要求

- Python 3.9+
- OpenAI 兼容的 API Key（GLM-4 / Kimi / MiniMax）

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/chinjaneking/strategy-agent.git
cd strategy-agent

# 2. 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt
```

### 配置 API Key

手动创建 `.env.local`（推荐）或 `.env`（兼容）并填写你的 API Key：

```ini
# 智谱 GLM-4（推荐）
GLM4_API_KEY=your_glm4_api_key_here
GLM4_BASE_URL=https://open.bigmodel.cn/api/paas/v4/
GLM4_MODEL=glm-4

# 月之暗面 Kimi
KIMI_API_KEY=your_kimi_api_key_here
KIMI_BASE_URL=https://api.moonshot.cn/v1
KIMI_MODEL=moonshot-v1-8k

# MiniMax
MINIMAX_API_KEY=your_minimax_api_key_here
MINIMAX_BASE_URL=https://api.minimax.chat/v1
MINIMAX_MODEL=abab6.5-chat

# 默认使用的模型
DEFAULT_MODEL_PROVIDER=glm4
```

如果 `.env` 和 `.env.local` 同时存在，运行时会优先使用 `.env.local` 中的值。

### 启动使用

**Web 界面（推荐）：**

```bash
streamlit run main_web.py
```

浏览器将自动打开 `http://localhost:8501`

**命令行界面：**

```bash
python main_cli.py
```

**管理员复盘终端（V2.1 新增）：**

用于录入实战反馈，驱动智能体持续学习进化：

```bash
python admin_feedback_cli.py
```

## 📚 功能详解

### 六步分析框架

谋策智能体对每个决策问题执行以下六步分析：

| 步骤 | 名称 | 核心方法 | 输出内容 |
|:---:|:---:|:---:|:---|
| 1 | **矛盾拆解** | 毛泽东思想·矛盾分析法 | 主要矛盾、次要矛盾、核心症结 |
| 2 | **谋略匹配** | 鬼谷子/孙子兵法 | 3-5 个贴合谋略及选择理由 |
| 3 | **方案推演** | 多维度分析 | 保守型 / 进攻型 / 灵活型 三套方案 |
| 4 | **风险评估** | 量化评估 | 高/中/低等级 + 具体风险点 + 规避措施 |
| 5 | **落地拆分** | 执行规划 | 周/月级别可执行步骤 + 关键里程碑 |
| 6 | **复盘提示** | 效果验证 | 可量化验证指标 + 调整时机 |

### 智慧体系

#### 📜 鬼谷子（纵横捭阖之术）

| 谋略 | 核心要义 | 应用场景 |
|:---:|:---:|:---|
| **捭阖** | 开合之道，欲取先予 | 谈判博弈、心理攻防 |
| **反应** | 以反求复，投石问路 | 试探虚实、信息收集 |
| **内楗** | 从内部契合，直击要害 | 精准切入关键决策者 |
| **抵巇** | 堵塞缝隙，防患未然 | 风险控制、危机预警 |
| **飞箝** | 先扬后抑，施加影响 | 说服引导、掌控节奏 |
| **忤合** | 审时度势，选择立场 | 站队决策、时机判断 |

#### ⚔️ 孙子兵法（战略战术之道）

| 谋略 | 核心要义 | 应用场景 |
|:---:|:---:|:---|
| **计篇** | 庙算为先，五事七计 | 重大决策前的全面评估 |
| **谋攻** | 不战而屈人之兵 | 非对抗性策略、外交手段 |
| **虚实** | 避实击虚，掌握主动 | 资源分配、竞争策略 |
| **九变** | 灵活变通，不拘一格 | 应急预案、动态调整 |
| **用间** | 知己知彼，情报为先 | 竞品分析、市场调研 |

#### 🚩 毛泽东思想（实事求是之法）

| 方法论 | 核心要义 | 应用场景 |
|:---:|:---:|:---|
| **实事求是** | 从实际出发，不唯书不唯上 | 现状调研、数据驱动决策 |
| **矛盾分析** | 抓主要矛盾与矛盾主要方面 | 问题诊断、优先级排序 |
| **群众路线** | 深入一线，发动集体智慧 | 团队决策、共识凝聚 |
| **游击战十六字诀** | 敌进我退，敌疲我打 | 弱势竞争、资源有限时 |
| **集中优势兵力** | 聚焦核心，不打无把握之仗 | 资源聚焦、单点突破 |
| **持久战** | 战略藐视，战术重视 | 长期规划、分阶段推进 |

## 💡 使用示例

### 示例 1：创业竞争决策

**问题**："竞品突然发起价格战，我方资金有限，该如何应对？"

**分析要点**：
- 运用孙子兵法"虚实篇"，避免正面价格战
- 运用"游击战十六字诀"，寻找细分市场突破
- 三套方案：差异化防守 / 侧翼进攻 / 联盟合纵

### 示例 2：职场 Offer 选择

**问题**："面临两个 offer，稳定大厂 vs 风险创业公司，如何决策？"

**分析要点**：
- 运用鬼谷子"忤合"分析时机与个人阶段匹配度
- 运用毛泽东思想"矛盾分析"识别核心诉求
- 三套方案：求稳路线 / 冒险路线 / 折中路线

### 示例 3：投资决策

**问题**："手上有 50 万，股市低迷是否适合入场？"

**分析要点**：
- 运用"实事求是"原则分析真实市场数据
- 运用"持久战"思维制定分阶段投入计划
- 三套方案：保守定投 / 分批抄底 / 观望等待

## 🔄 模型切换

修改 `.env` 文件中的 `DEFAULT_MODEL_PROVIDER`：

```ini
# 使用智谱 GLM-4（推荐，逻辑推演能力强）
DEFAULT_MODEL_PROVIDER=glm4

# 使用月之暗面 Kimi（适合长文本分析）
DEFAULT_MODEL_PROVIDER=kimi

# 使用 MiniMax（语言情商高）
DEFAULT_MODEL_PROVIDER=minimax
```
